Foresi keeps contacts, invoices, payments, received documents, projects and tasks in one application, so a job runs in one place from the first contact to the paid invoice. You run it on your own server under the AGPL, the data stays yours, and a REST API and an MCP server let your own tools and AI assistants work with it. Foresi is at an early stage (0.x): Czech rules for VAT, invoices and the business register come first, and other countries follow as country modules.
